# Giz & Gabarito

Site público do app Giz & Gabarito, publicado pelo GitHub Pages em https://darthkley.github.io/.

- `privacidade/index.html`: política de privacidade, a mesma de `loja/politica-de-privacidade.html` no repositório do app.
- `sugerir/index.html` e `reportar/index.html`: sugestão de concurso e aviso de erro numa questão.
- `estudar/`: apostilas (resumos sem anúncios, com fontes oficiais). `estudar/index.html` lista todas.

As páginas de `privacidade/`, `sugerir/`, `reportar/` e `estudar/` são geradas por `ferramentas-mulder/loja/montar_site.py`, no repositório do app. Não edite à mão: edite os modelos e as apostilas de lá e gere de novo.
