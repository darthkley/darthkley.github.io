  • As operações com irracionais:
    • a soma e o produto de dois racionais são sempre racionais;
    • a soma de um racional com um irracional é sempre irracional, e o produto de um racional não nulo por um irracional também;
    • mas a soma ou o produto de dois irracionais pode ser racional: √2 + (−√2) = 0 e √2 · √2 = 2. O conjunto dos irracionais não é fechado para essas operações.
  • A prova clássica de que √2 é irracional (por absurdo): se √2 = a/b, com a fração irredutível, então a² = 2b², e a é par; escrevendo a = 2k, vem b² = 2k², e b também é par, o que contradiz a fração ser irredutível.
  • As propriedades das operações nos reais: comutativa e associativa (na adição e na multiplicação), elemento neutro (0 e 1), oposto e inverso (exceto o zero, que não tem inverso) e a distributiva. A divisão por zero não é definida.
  • Os números primos têm exatamente dois divisores naturais: 1 e eles mesmos. O 1 não é primo, e o 2 é o único primo par.
    • Pelo teorema fundamental da aritmética, todo natural maior que 1 se decompõe em fatores primos de maneira única, a menos da ordem.
    • Euclides provou que há infinitos primos.
    • O crivo de Eratóstenes encontra os primos riscando os múltiplos. Para saber se um número n é primo, basta testar a divisão pelos primos até √n.
  • O mdc e o mmc: para dois naturais, mdc(a, b) × mmc(a, b) = a × b. Dois números são primos entre si quando o mdc deles é 1. O mdc também sai pelo algoritmo de Euclides, das divisões sucessivas.
  • Os critérios de divisibilidade: por 2 (termina em algarismo par), por 3 (a soma dos algarismos é divisível por 3), por 4 (os dois últimos algarismos formam um número divisível por 4), por 5 (termina em 0 ou 5), por 9 (a soma dos algarismos é divisível por 9), por 10 (termina em 0) e por 11 (a diferença entre as somas dos algarismos de ordem par e ímpar é divisível por 11).

As funções: conceitos gerais

  • A definição: uma função f: A → B associa cada elemento de A a um único elemento de B. A é o domínio, B é o contradomínio, e o conjunto dos valores efetivamente atingidos é a imagem. No gráfico, toda reta vertical traçada sobre o domínio corta a curva em um só ponto.
  • A igualdade de funções: duas funções são iguais quando têm o mesmo domínio, o mesmo contradomínio e a mesma lei para todo x do domínio. Por exemplo, f(x) = x e g(x) = x²/x não são iguais: g não está definida em x = 0.
  • O domínio de uma função real, quando não é dado, é o maior conjunto em que a lei faz sentido:
    • o denominador não pode ser zero;
    • o radicando de raiz de índice par deve ser maior ou igual a zero;
    • o logaritmando deve ser positivo, e a base, positiva e diferente de 1.
Injetiva, sobrejetiva e bijetiva
TipoDefiniçãoNo gráficoExemplo
InjetivaElementos diferentes do domínio têm imagens diferentesToda reta horizontal corta o gráfico no máximo uma vezf(x) = 2x + 1; f(x) = eˣ
SobrejetivaA imagem é igual ao contradomínioToda reta horizontal na altura de um ponto do contradomínio corta o gráficof(x) = x³, de ℝ em ℝ
BijetivaInjetiva e sobrejetiva ao mesmo tempoExatamente um corte por reta horizontalf(x) = 2x + 1, de ℝ em ℝ
  • O contradomínio importa: f(x) = x² de ℝ em ℝ não é injetiva (f(−2) = f(2)) nem sobrejetiva (não atinge os negativos). Mas f(x) = x² de [0, ∞) em [0, ∞) é bijetiva.
  • A função inversa: só as funções bijetivas têm inversa. Para achá-la, troque x por y e isole y. O gráfico da inversa é o simétrico do gráfico de f em relação à reta y = x. Exemplo: a inversa de f(x) = 2x + 1 é f⁻¹(x) = (x − 1)/2. A exponencial e a logarítmica de mesma base são inversas uma da outra.
  • A composição: (g∘f)(x) = g(f(x)): aplica-se primeiro f e depois g. Em geral, g∘f ≠ f∘g. Exemplo: com f(x) = x + 1 e g(x) = x², g(f(x)) = (x + 1)², mas f(g(x)) = x² + 1.
  • O crescimento: f é crescente num intervalo se x₁ < x₂ implica f(x₁) < f(x₂), e decrescente se implica f(x₁) > f(x₂).
  • A paridade:
    • f é par se f(−x) = f(x) para todo x do domínio: o gráfico é simétrico em relação ao eixo y. Exemplos: x², x⁴, |x|, cos x;
    • f é ímpar se f(−x) = −f(x): o gráfico é simétrico em relação à origem. Exemplos: x, x³, sen x, tg x;
    • a maioria das funções não é par nem ímpar, como f(x) = x + 1 e eˣ. A soma de duas ímpares é ímpar, e o produto de duas ímpares é par.
  • Os zeros e o sinal: os zeros (raízes) são os valores de x com f(x) = 0, onde o gráfico corta o eixo x. O estudo do sinal diz onde f é positiva, negativa ou nula. Pelo teorema do valor intermediário (Bolzano), uma função contínua que muda de sinal num intervalo tem um zero nele.

As funções afim, quadrática e modular

  • A função afim: f(x) = ax + b, com gráfico em forma de reta.
    • a é a taxa de variação (coeficiente angular): a = Δy/Δx. Se a > 0, f é crescente; se a < 0, decrescente; se a = 0, constante;
    • b é o valor em x = 0, onde a reta corta o eixo y;
    • o zero é x = −b/a;
    • com b = 0, a função é linear e representa uma proporcionalidade direta.

Caiu em 2022

Item 56, certo: a reta passa por (2, 0) e (−3, 5). O coeficiente angular é (5 − 0)/(−3 − 2) = −1, e f(x) = −x + 2. Então f(4x) = −4x + 2 = 2(1 − 2x), que é divisível por 2 para todo x inteiro.

  • A função quadrática: f(x) = ax² + bx + c, com a ≠ 0, cujo gráfico é uma parábola.
    • Se a > 0, a concavidade é para cima, e há ponto de mínimo; se a < 0, para baixo, e há ponto de máximo.
    • c é o valor em x = 0, onde a parábola corta o eixo y.
    • As raízes são x = (−b ± √Δ)/(2a), com Δ = b² − 4ac. Se Δ > 0, há duas raízes reais distintas; se Δ = 0, uma raiz dupla; se Δ < 0, nenhuma raiz real.
    • A soma das raízes é −b/a, e o produto, c/a.
    • O vértice é o ponto (xv, yv), com xv = −b/(2a) e yv = −Δ/(4a). O eixo de simetria é a reta vertical x = xv.
    • A forma fatorada é a(x − x₁)(x − x₂), e a canônica, a(x − xv)² + yv.

Caiu em 2022

Item 57, errado: o gráfico mostrava a parábola passando por B = (0, 5) e com vértice em A = (1, 6). Então c = 5, e xv = −b/(2a) = 1, logo b = −2a. Com f(1) = 6, vem a + b + 5 = 6, ou a + b = 1. Substituindo, a − 2a = 1, logo a = −1 e b = 2, e não −2.

  • A função modular: |x| = x se x ≥ 0, e |x| = −x se x < 0. O gráfico de f(x) = |x| tem a forma de um V, com vértice na origem.
    • |x| é a distância de x até 0, e |x − a|, a distância de x até a.
    • |x| = k, com k > 0, dá x = k ou x = −k.
    • |x| < k equivale a −k < x < k; e |x| > k equivale a x < −k ou x > k.
    • √(x²) = |x|, e não x.

As funções polinomiais, exponenciais e logarítmicas

  • Os polinômios: p(x) = aₙxⁿ + … + a₁x + a₀, de grau n (com aₙ ≠ 0).
    • Pelo teorema fundamental da álgebra, todo polinômio de grau n ≥ 1 tem exatamente n raízes complexas, contadas com multiplicidade.
    • Com coeficientes reais, as raízes complexas não reais aparecem aos pares conjugados. Por isso todo polinômio real de grau ímpar tem pelo menos uma raiz real.
    • Pelo teorema do resto, o resto da divisão de p(x) por (x − a) é p(a). Se p(a) = 0, então (x − a) é fator de p(x). O dispositivo de Briot-Ruffini faz essa divisão de forma prática.
    • As relações de Girard ligam os coeficientes à soma e ao produto das raízes.
  • A função exponencial: f(x) = aˣ, com a > 0 e a ≠ 1.
    • É crescente se a > 1 e decrescente se 0 < a < 1.
    • É sempre positiva: a imagem é (0, ∞), e o gráfico passa por (0, 1) e não toca o eixo x.
    • De ℝ em (0, ∞), é bijetiva.
    • A base mais importante é o número e ≈ 2,718.
    • Modela juros compostos, crescimento de populações e de bactérias, e decaimento radioativo (a meia-vida).
  • O logaritmo: loga b = x significa aˣ = b, com a > 0, a ≠ 1 e b > 0.
    • As propriedades: log(m·n) = log m + log n; log(m/n) = log m − log n; log(mᵏ) = k·log m; e a mudança de base, loga b = logc b / logc a.
    • O logaritmo natural (ln) tem base e.
    • A função logarítmica f(x) = loga x, de domínio (0, ∞), é a inversa da exponencial de mesma base. É crescente se a > 1, passa por (1, 0) e não toca o eixo y.
    • Escalas logarítmicas aparecem no pH, nos decibéis e na magnitude dos terremotos.

As equações e inequações

  • A equação do 1º grau (ax + b = 0, com a ≠ 0) tem a solução x = −b/a. A do 2º grau se resolve pela fórmula com Δ, por fatoração, por completamento de quadrado ou por soma e produto.
  • As inequações: ao multiplicar ou dividir os dois lados por um número negativo, o sentido da desigualdade se inverte. Nas inequações do 2º grau, estuda-se o sinal da parábola: se a > 0, ela é negativa entre as raízes e positiva fora delas.
  • As inequações-produto e quociente se resolvem com o quadro de sinais. No quociente, o denominador nunca pode ser zero.
  • As equações exponenciais se resolvem igualando as bases (2ˣ = 32 dá x = 5) ou com logaritmos. As logarítmicas exigem conferir a condição de existência: o logaritmando deve ser positivo.
  • As equações irracionais, com x dentro de raiz, pedem que se elevem os dois lados ao quadrado e depois se verifiquem as soluções, porque podem surgir raízes estranhas.

As sequências e progressões

  • A sequência de Fibonacci: 1, 1, 2, 3, 5, 8, 13, 21, …, em que cada termo é a soma dos dois anteriores (Fn+2 = Fn+1 + Fn). Leonardo de Pisa a apresentou no Liber Abaci (1202), com um problema de reprodução de coelhos. A razão entre termos consecutivos, Fn+1/Fn, converge para a razão áurea, φ = (1 + √5)/2 ≈ 1,618. Ela aparece em espirais de girassóis, pinhas e conchas.
  • A progressão aritmética (PA) soma sempre a mesma razão r:
    • termo geral: aₙ = a₁ + (n − 1)·r;
    • soma dos n primeiros termos: Sₙ = (a₁ + aₙ)·n/2. Diz a história que Gauss, menino, somou de 1 a 100 assim: 50 pares de 101, ou 5.050;
    • numa PA, cada termo é a média aritmética do anterior com o seguinte;
    • uma PA com r ≠ 0 é crescente ou decrescente e não converge. Os termos não alternam de sinal (no máximo mudam de sinal uma vez).
  • A progressão geométrica (PG) multiplica sempre pela mesma razão q:
    • termo geral: aₙ = a₁·qⁿ⁻¹;
    • soma dos n primeiros termos: Sₙ = a₁(qⁿ − 1)/(q − 1), para q ≠ 1;
    • numa PG de termos positivos, cada termo é a média geométrica do anterior com o seguinte: (an)² = an−1·an+1;
    • se |q| < 1, a PG converge para 0, e a soma infinita vale a₁/(1 − q). Exemplo: 1 + 1/2 + 1/4 + … = 2;
    • se q < 0, os termos alternam de sinal.
  • A sequência constante (3, 3, 3, …) é ao mesmo tempo uma PA (de razão 0) e uma PG (de razão 1).
  • A convergência: uma sequência converge para L quando os seus termos ficam tão perto de L quanto se queira, a partir de certa posição. Toda sequência monótona e limitada converge. Uma sequência que cresce sem limite ou que oscila entre dois valores diverge.

As matrizes e os determinantes

  • As matrizes: uma matriz m × n tem m linhas e n colunas. Há a quadrada (m = n), a identidade (1 na diagonal principal e 0 fora dela), a nula, a diagonal, a triangular, a transposta (Aᵗ, com as linhas trocadas pelas colunas) e a simétrica (A = Aᵗ).
  • As operações:
    • soma-se e multiplica-se por número termo a termo;
    • o produto A·B só existe se o número de colunas de A for igual ao de linhas de B. Cada elemento é a soma dos produtos de uma linha de A pela coluna correspondente de B;
    • o produto de matrizes não é comutativo: em geral, A·B ≠ B·A;
    • a inversa A⁻¹, com A·A⁻¹ = I, existe só para matrizes quadradas de determinante diferente de zero.
  • Os determinantes:
    • de ordem 2: det = ad − bc, para a matriz de linhas (a b) e (c d);
    • de ordem 3: pela regra de Sarrus (repetem-se as duas primeiras colunas, somam-se os produtos das diagonais descendentes e subtraem-se os das ascendentes) ou pelo teorema de Laplace (expansão por uma linha ou coluna, com os cofatores);
    • uma matriz de determinante nulo é singular e não tem inversa.

Os sistemas lineares

  • A classificação:
    • possível e determinado (SPD): uma única solução;
    • possível e indeterminado (SPI): infinitas soluções;
    • impossível (SI): nenhuma solução.
    Um sistema linear nunca tem exatamente duas soluções: ou tem uma, ou nenhuma, ou infinitas.
  • A regra de Cramer: num sistema quadrado (n equações e n incógnitas) com determinante D ≠ 0, ele é SPD, e cada incógnita vale Dₓ/D, em que Dₓ é o determinante com a coluna dessa incógnita trocada pelos termos independentes. Se D = 0, o sistema é SPI ou SI, e é preciso escalonar.
  • O escalonamento (método de Gauss): com operações nas equações, chega-se a uma forma "em escada". Uma equação do tipo 0 = 5 indica SI; sobrar menos equações que incógnitas, sem contradição, indica SPI.
  • O sistema homogêneo (todos os termos independentes iguais a zero) é sempre possível, porque tem a solução trivial (todas as incógnitas nulas). Ele é SPD (só a trivial) se D ≠ 0, e SPI se D = 0.
  • Mais incógnitas que equações (m < n): o sistema nunca é determinado. Ou é impossível, ou tem infinitas soluções.
  • Interpretação geométrica: em duas incógnitas, cada equação é uma reta, e as duas retas podem ser concorrentes (SPD), coincidentes (SPI) ou paralelas distintas (SI). Em três incógnitas, cada equação é um plano.

Caiu em 2022

  • Item 80, errado: com m < n, o sistema Ax = b não "nunca terá solução": pode ter infinitas. Por exemplo, x + y = 2 tem uma equação, duas incógnitas e infinitas soluções.
  • Item 83, errado: o sistema homogêneo de 5 equações nas incógnitas x, y, z, w e k só tem a solução trivial. Da 2ª e da 3ª equações, x + z = 0; da 1ª, k = 0; da 4ª, z = 0; da 5ª, w = 0; e então y = 0 e x = 0. O espaço solução tem um elemento só, e não infinitos.

Os números complexos

  • A forma algébrica: z = a + bi, com i² = −1. a é a parte real, e b, a imaginária. Se a = 0 e b ≠ 0, z é imaginário puro. As potências de i se repetem de 4 em 4: i⁰ = 1, i¹ = i, i² = −1, i³ = −i.
  • O conjugado de z = a + bi é z̄ = a − bi. Vale z + z̄ = 2a e z·z̄ = a² + b². Para dividir, multiplicam-se o numerador e o denominador pelo conjugado do denominador.
  • O plano de Argand-Gauss: z corresponde ao ponto (a, b). O módulo é |z| = √(a² + b²), a distância até a origem, e o argumento θ é o ângulo com o eixo real. |z − z₀| é a distância entre z e z₀: |z − z₀| = r descreve uma circunferência de centro z₀ e raio r.
  • A forma trigonométrica (polar): z = |z|·(cos θ + i·sen θ).
    • Na multiplicação, multiplicam-se os módulos e somam-se os argumentos; na divisão, dividem-se os módulos e subtraem-se os argumentos.
    • Pela fórmula de De Moivre, zⁿ = |z|ⁿ·(cos nθ + i·sen nθ).
    • As n raízes n-ésimas de um complexo têm o mesmo módulo e argumentos espaçados de 360°/n: são os vértices de um polígono regular de n lados centrado na origem. As raízes cúbicas de 1 (1, −1/2 + i√3/2 e −1/2 − i√3/2) formam um triângulo equilátero.
  • A história: os complexos surgiram no século XVI, na resolução das equações do 3º grau (Cardano, Tartaglia e Bombelli), e não das do 2º. Euler introduziu o símbolo i, e Gauss consolidou a representação no plano.

Caiu em 2022

  • Item 71, errado: −√2/2 + i·√2/2 tem módulo 1 e argumento 135° (3π/4). Pela fórmula de De Moivre, a 12ª potência tem argumento 12 × 135° = 1.620° = 4 × 360° + 180°: dá cos 180° + i·sen 180° = −1. A parte imaginária é zero, e não positiva.
  • Item 72, certo: z₀ = 1, z₁ e z₂ são as três raízes cúbicas da unidade e formam um triângulo equilátero.
  • Item 73, errado: com z = a + bi, a equação |2z − 1|² + 2|z + z̄|² = 3/2 fica (2a − 1)² + 4b² + 8a² = 3/2, ou 12a² − 4a + 4b² = 1/2. Completando o quadrado: 12(a − 1/6)² + 4b² = 5/6. É mesmo uma elipse, mas com centro em (1/6, 0), e não em (1/2, 0).
  • Item 74, certo: em z̄² = 4z, se z = 0, a igualdade vale. Se z ≠ 0, tomando módulos, |z|² = 4|z|, e |z| = 4; com z = 4(cos θ + i·sen θ), a equação pede cos(−2θ) = cos θ e sen(−2θ) = sen θ, ou 3θ múltiplo de 360°: θ = 0°, 120° ou 240°. São quatro soluções.

O produto de dois números irracionais é sempre um número irracional.Toque para ver a resposta

Errado. Contraexemplo: √2 · √2 = 2, que é racional.

Certo. 0,2727… = 27/99 = 3/11. Toda dízima periódica é racional.

Para verificar se 221 é primo, basta testar a divisão pelos primos menores ou iguais a 14; como 221 = 13 × 17, ele não é primo.Toque para ver a resposta

Certo. Como √221 ≈ 14,9, basta testar os primos até 13, e 13 divide 221.

Se o mdc de dois números naturais é 6 e o mmc é 60, então o produto desses números é 360.Toque para ver a resposta

Certo. Para dois naturais, mdc × mmc = a × b: 6 × 60 = 360.

As funções f(x) = √(x²) e g(x) = x, definidas nos reais, são iguais.Toque para ver a resposta

Errado. √(x²) = |x|, que difere de x para os negativos: f(−2) = 2, e g(−2) = −2.

O domínio da função f(x) = log(x − 3) é o conjunto dos números reais maiores que 3.Toque para ver a resposta

Certo. O logaritmando deve ser positivo: x − 3 > 0.

A função f: ℝ → ℝ dada por f(x) = x² + 1 é injetiva.Toque para ver a resposta

Errado. f(−1) = f(1) = 2: elementos diferentes têm a mesma imagem.

A inversa da função bijetiva f(x) = 3x − 6 é f⁻¹(x) = x/3 + 2.Toque para ver a resposta

Certo. De y = 3x − 6, vem x = (y + 6)/3 = y/3 + 2. Trocando as letras, f⁻¹(x) = x/3 + 2.

Errado. f(g(1)) = f(4) = 8, e g(f(1)) = g(2) = 5. A composição não é comutativa.

A função f(x) = x³ − x é ímpar.Toque para ver a resposta

Certo. f(−x) = −x³ + x = −(x³ − x) = −f(x).

A equação |x − 2| = 5 tem como soluções x = 7 e x = −3.Toque para ver a resposta

Errado. As raízes complexas não reais vêm aos pares conjugados. Com grau ímpar, sobra pelo menos uma raiz real.
